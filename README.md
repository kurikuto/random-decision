# ランダム決定ツール

リストからランダムに 1 つを選択して表示する Web アプリケーションです。

## 機能

- **リスト管理**: 複数のリスト（料理、学習内容、占いなど）を自由に作成
- **アイテム管理**: 各リストにタイトル、内容、その他情報を持つアイテムを追加
- **ランダム選択**: リストからランダムに 1 つのアイテムを選択して表示
- **編集・削除**: リストとアイテムの編集・削除が可能

## 技術スタック

- React 19
- TypeScript
- Vite
- Dexie.js (IndexedDB wrapper)

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build
```

## 使い方

1. トップ画面でリストを選択または新規作成
2. リスト詳細画面でアイテムを追加・編集
3. 「ランダム選択」ボタンをクリック
4. 選択結果が表示されます
